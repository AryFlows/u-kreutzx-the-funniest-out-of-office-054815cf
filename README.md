## The entry (129 characters)

> I'm out of the office until Monday. My auto-reply is the only thing still answering emails, and it has already asked for a raise.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` (or `/output` when unset).

## Gate

`entry.txt` must be UTF-8 text of 1 to 140 characters, a single line, and
not only whitespace. This entry is 129 characters, one line, plain ASCII.

## Why this line

The first sentence sets up the most ordinary out-of-office reply there is.
The second sentence turns it: the auto-reply — the thing doing the work
while its owner is away — is the one demanding a raise. It is a reply a
real person would actually set, with a twist nobody sees coming in the
last few words, and nothing in it could be cut without losing the laugh.

It also quietly flatters the reader: everyone who has ever left an inbox
unattended knows the auto-reply is the only employee that never takes a
day off.
